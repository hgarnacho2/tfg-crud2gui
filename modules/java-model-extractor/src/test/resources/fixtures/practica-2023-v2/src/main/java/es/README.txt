Práctica FI UNED – solución Java (modelo de etapa 3)

Incluye las clases:
- Usuario, Producto (abstracta), ProductoRopa, ProductoElectronica
- T_Estado, PlataformaCompraVenta
- LanzadorEtapa3_1 para ejecutar una prueba

Compilar desde esta carpeta:
    javac *.java

Ejecutar:
    java LanzadorEtapa3_1

Se implementan también las operaciones opcionales de la etapa 2: filtrar por estado,
listar productos de un usuario y buscar por palabra en la descripción.

Nota: el PDF aportado corresponde al curso 2023/24. La solución sigue las firmas y
funcionalidades descritas en ese documento; contrasta el enunciado de tu curso antes
de entregar y asegúrate de comprender y adaptar el código.
